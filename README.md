# 🎬 Film Quiz

An interactive film trivia quiz built as the final project in my JavaScript 1 course.

🔗 **Live Demo:** [View Website](https://css95.github.io/ankademin_quiz)

## Features
- Three question types: true/false, multiple choice, and multiple correct answers
- Score tracking
- Detailed results review after completing the quiz
- Dark mode toggle

## Tech Stack
- HTML
- CSS
- JavaScript

## Run Locally
```bash
git clone https://github.com/css95/ankademin_quiz.git
cd ankademin_quiz
```

Then open index.html directly in your browser.
